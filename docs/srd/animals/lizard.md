# Lizard

Tiny Beast, Unaligned

Bonus Actions
Trample. Dexterity Saving Throw: DC 18, one creature
within 5 feet that has the Prone condition. Failure: 29
(4d10 + 7) Bludgeoning damage. Success: Half damage.
